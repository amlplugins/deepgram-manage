# @amlplugins/deepgram-manage

Native `@deepgram/sdk` SDK re-exported under the `@amlplugins` namespace.

> Deepgram Manage — projects, keys, balances, usage, model lists, members across the Deepgram console.

## Install

```bash
npm install @amlplugins/deepgram-manage
```

## Use

```ts
import { /* named exports from @deepgram/sdk */ } from "@amlplugins/deepgram-manage";
// or
import sdk from "@amlplugins/deepgram-manage";
```

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
